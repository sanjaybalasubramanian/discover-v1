OPTION A: Deploy from CLI

2. vercel login
3. cd v:/discover

5. vercel env add DATABASE_URL

1. Go to: https://vercel.com
2. Click "Add New" → "Project"
3. Select "Import Git Repository"
4. Choose: sanjaybalasubramanian/discover-v1
5. Vercel auto-detects vercel.json configuration
6. Add environment variable:
   - Name: DATABASE_URL
   - Value: postgresql://postgres.twwvyllmqjzrqmsnamhq:...

8. Done! Get your URL: https://discover-v1.vercel.app
